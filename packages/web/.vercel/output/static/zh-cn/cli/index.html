CLI

SlopCode CLI 在不带任何参数运行时，默认启动 TUI。

但它也接受本页面中记录的命令，使您可以通过编程方式与 SlopCode 进行交互。

tui

启动 SlopCode 终端用户界面。

标志

标志 简写 描述
--continue -c 继续上一个会话
--session -s 要继续的会话 ID
--fork 继续时分叉会话（与 --continue 或 --session 配合使用）
--prompt 要使用的提示词
--model -m 要使用的模型，格式为 provider/model
--agent 要使用的代理
--port 监听端口
--hostname 监听主机名

命令

SlopCode CLI 还提供以下命令。

agent

管理 SlopCode 的代理。

attach

将终端连接到已通过 serve 或 web 命令启动的 SlopCode 后端服务器。

这允许将 TUI 与远程 SlopCode 后端配合使用。例如：

标志

标志 简写 描述
--dir 启动 TUI 的工作目录
--session -s 要继续的会话 ID

create

使用自定义配置创建新的代理。

此命令将引导您使用自定义系统提示词和工具配置来创建新的代理。

list

列出所有可用的代理。

auth

管理提供商的凭据和登录信息的命令。

login

SlopCode 基于 Models.dev 的提供商列表运行，因此您可以使用 slopcode auth login 为任何想要使用的提供商配置 API 密钥。密钥存储在 ~/.local/share/slopcode/auth.json 中。

SlopCode 启动时会从凭据文件加载提供商信息，同时也会加载环境变量或项目中 .env 文件中定义的密钥。

list

列出凭据文件中存储的所有已认证提供商。

或使用简写版本。

logout

从凭据文件中清除提供商信息以完成登出。

github

管理用于仓库自动化的 GitHub 代理。

install

在您的仓库中安装 GitHub 代理。

此命令会设置必要的 GitHub Actions 工作流并引导您完成配置过程。了解更多。

run

运行 GitHub 代理。通常在 GitHub Actions 中使用。

标志
标志 描述
--event 用于运行代理的 GitHub 模拟事件
--token GitHub 个人访问令牌

mcp

管理 Model Context Protocol 服务器。

add

将 MCP 服务器添加到您的配置中。

此命令将引导您添加本地或远程 MCP 服务器。

list

列出所有已配置的 MCP 服务器及其连接状态。

或使用简写版本。

auth

对支持 OAuth 的 MCP 服务器进行认证。

如果您不提供服务器名称，系统将提示您从可用的支持 OAuth 的服务器中进行选择。

您还可以列出支持 OAuth 的服务器及其认证状态。

或使用简写版本。

logout

移除 MCP 服务器的 OAuth 凭据。

debug

调试 MCP 服务器的 OAuth 连接问题。

models

列出已配置提供商的所有可用模型。

此命令以 provider/model 的格式显示所有已配置提供商中可用的模型。

这对于确定在配置文件中使用的确切模型名称非常有用。

您可以选择传入提供商 ID 来按提供商筛选模型。

标志

标志 描述
--refresh 从 models.dev 刷新模型缓存
--verbose 使用更详细的模型输出（包含费用等元数据）

使用 --refresh 标志可以更新缓存的模型列表。当提供商新增了模型并且您希望在 SlopCode 中看到它们时，此功能非常有用。

run

以非交互模式运行 SlopCode，直接传入提示词。

标志

标志 简写 描述
--command 要运行的命令，使用 message 作为参数
--continue -c 继续上一个会话
--session -s 要继续的会话 ID
--fork 继续时分叉会话（与 --continue 或 --session 配合使用）
--share 分享会话
--model -m 要使用的模型，格式为 provider/model
--agent 要使用的代理
--file -f 附加到消息的文件
--format 格式：default（格式化输出）或 json（原始 JSON 事件）
--title 会话标题（未提供值时使用截断的提示词）
--attach 连接到正在运行的 slopcode 服务器（例如 http://localhost:4096）
--port 本地服务器端口（默认为随机端口）

serve

启动无界面的 SlopCode 服务器以提供 API 访问。查看服务器文档了解完整的 HTTP 接口。

此命令启动一个 HTTP 服务器，提供对 SlopCode 功能的 API 访问，无需 TUI 界面。设置 SLOPCODE_SERVER_PASSWORD 可启用 HTTP 基本认证（用户名默认为 slopcode）。

标志

标志 描述
--port 监听端口
--hostname 监听主机名
--mdns 启用 mDNS 发现
--cors 允许 CORS 的额外浏览器来源

session

管理 SlopCode 会话。

list

列出所有 SlopCode 会话。

标志
标志 简写 描述
--max-count -n 限制为最近 N 个会话
--format 输出格式：table 或 json（默认 table）

stats

显示 SlopCode 会话的 Token 用量和费用统计信息。

标志

标志 描述
--days 显示最近 N 天的统计信息（默认为所有时间）
--tools 显示的工具数量（默认为全部）
--models 显示模型用量明细（默认隐藏）。传入数字可显示前 N 个
--project 按项目筛选（默认为所有项目，传入空字符串表示当前项目）

export

将会话数据导出为 JSON。

如果您不提供会话 ID，系统将提示您从可用的会话中进行选择。

import

从 JSON 文件或 SlopCode 分享链接导入会话数据。

您可以从本地文件或 SlopCode 分享链接导入。

web

启动带有 Web 界面的无界面 SlopCode 服务器。

此命令启动一个 HTTP 服务器并打开浏览器，通过 Web 界面访问 SlopCode。设置 SLOPCODE_SERVER_PASSWORD 可启用 HTTP 基本认证（用户名默认为 slopcode）。

标志

标志 描述
--port 监听端口
--hostname 监听主机名
--mdns 启用 mDNS 发现
--cors 允许 CORS 的额外浏览器来源

acp

启动 ACP（Agent Client Protocol）服务器。

此命令启动一个通过 stdin/stdout 使用 nd-JSON 进行通信的 ACP 服务器。

标志

标志 描述
--cwd 工作目录
--port 监听端口
--hostname 监听主机名

uninstall

卸载 SlopCode 并删除所有相关文件。

标志

标志 简写 描述
--keep-config -c 保留配置文件
--keep-data -d 保留会话数据和快照
--dry-run 显示将被删除的内容但不实际删除
--force -f 跳过确认提示

upgrade

将 SlopCode 更新到最新版本或指定版本。

更新到最新版本。

更新到指定版本。

标志

标志 简写 描述
--method -m 使用的安装方式：curl、npm、pnpm、yarn、bun、nix、brew、macports、apt、zypper、dnf、yum、apk、pkg、pacman、paru、snap、choco、scoop

全局标志

SlopCode CLI 接受以下全局标志。

标志 简写 描述
--help -h 显示帮助信息
--version -v 打印版本号
--print-logs 将日志输出到 stderr
--log-level 日志级别（DEBUG、INFO、WARN、ERROR）

环境变量

SlopCode 可以通过环境变量进行配置。

变量 类型 描述
SLOPCODE_AUTO_SHARE boolean 自动分享会话
SLOPCODE_GIT_BASH_PATH string Windows 上 Git Bash 可执行文件的路径
SLOPCODE_CONFIG string 配置文件路径
SLOPCODE_CONFIG_DIR string 配置目录路径
SLOPCODE_CONFIG_CONTENT string 内联 JSON 配置内容
SLOPCODE_DISABLE_AUTOUPDATE boolean 禁用自动更新检查
SLOPCODE_DISABLE_PRUNE boolean 禁用旧数据清理
SLOPCODE_DISABLE_TERMINAL_TITLE boolean 禁用自动终端标题更新
SLOPCODE_PERMISSION string 内联 JSON 权限配置
SLOPCODE_DISABLE_DEFAULT_PLUGINS boolean 禁用默认插件
SLOPCODE_DISABLE_LSP_DOWNLOAD boolean 禁用 LSP 服务器自动下载
SLOPCODE_ENABLE_EXPERIMENTAL_MODELS boolean 启用实验性模型
SLOPCODE_DISABLE_AUTOCOMPACT boolean 禁用自动上下文压缩
SLOPCODE_DISABLE_CLAUDE_CODE boolean 禁用读取 .claude（提示词 + 技能）
SLOPCODE_DISABLE_CLAUDE_CODE_PROMPT boolean 禁用读取 ~/.claude/CLAUDE.md
SLOPCODE_DISABLE_CLAUDE_CODE_SKILLS boolean 禁用加载 .claude/skills
SLOPCODE_DISABLE_MODELS_FETCH boolean 禁用从远程源获取模型
SLOPCODE_FAKE_VCS string 用于测试目的的模拟 VCS 提供商
SLOPCODE_DISABLE_FILETIME_CHECK boolean 禁用文件时间检查优化
SLOPCODE_CLIENT string 客户端标识符（默认为 cli）
SLOPCODE_ENABLE_EXA boolean 启用 Exa 网络搜索工具
SLOPCODE_SERVER_PASSWORD string 为 serve/web 启用基本认证
SLOPCODE_SERVER_USERNAME string 覆盖基本认证用户名（默认为 slopcode）
SLOPCODE_MODELS_URL string 自定义模型配置获取 URL

实验性功能

这些环境变量用于启用可能会更改或移除的实验性功能。

变量 类型 描述
SLOPCODE_EXPERIMENTAL boolean 启用所有实验性功能
SLOPCODE_EXPERIMENTAL_ICON_DISCOVERY boolean 启用图标发现
SLOPCODE_EXPERIMENTAL_DISABLE_COPY_ON_SELECT boolean 禁用 TUI 中的选中即复制
SLOPCODE_EXPERIMENTAL_BASH_DEFAULT_TIMEOUT_MS number bash 命令的默认超时时间（毫秒）
SLOPCODE_EXPERIMENTAL_OUTPUT_TOKEN_MAX number LLM 响应的最大输出 Token 数
SLOPCODE_EXPERIMENTAL_FILEWATCHER boolean 启用整个目录的文件监听器
SLOPCODE_EXPERIMENTAL_OXFMT boolean 启用 oxfmt 格式化器
SLOPCODE_EXPERIMENTAL_LSP_TOOL boolean 启用实验性 LSP 工具
SLOPCODE_EXPERIMENTAL_DISABLE_FILEWATCHER boolean 禁用文件监听器
SLOPCODE_EXPERIMENTAL_EXA boolean 启用实验性 Exa 功能
SLOPCODE_EXPERIMENTAL_LSP_TY boolean 启用实验性 LSP 类型检查
SLOPCODE_EXPERIMENTAL_MARKDOWN boolean 启用实验性 Markdown 功能
SLOPCODE_EXPERIMENTAL_PLAN_MODE boolean 启用计划模式
