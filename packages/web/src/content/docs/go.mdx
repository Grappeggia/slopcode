SlopCode Go is a $10 per month subscription that gives you reliable access to popular open coding models with generous usage limits.

It works like any other provider in SlopCode. Subscribe in [SlopCode Zen](https://slopcode.dev/zen), copy your API key, and connect it in the TUI.

---

## Understand it

Open models are now strong enough for serious coding work, but provider quality and latency still vary a lot.

SlopCode Go packages a tested set of model and provider combinations that the team feels good recommending.

---

## Get started

1. Open [SlopCode Zen](https://slopcode.dev/zen), enable SlopCode Go, and copy your API key.
2. Run `/connect` in the TUI, choose `SlopCode Go`, and paste the key.
3. Run `/models` to see the models currently available through the provider.

:::note
Only one member per workspace can subscribe to SlopCode Go.
:::

## Check limits

- **5 hour limit** - $12 of usage
- **Weekly limit** - $30 of usage
- **Monthly limit** - $60 of usage

## Review privacy

SlopCode Go is designed primarily for international users, with models hosted in the US, EU, and Singapore for stable global access.

Providers follow a zero-retention policy and do not use your data for model training.

---

## See goals

SlopCode Go is built to:

1. Make AI coding more accessible with a low cost subscription.
2. Provide reliable access to strong open coding models.
3. Curate combinations that are tested for coding agent use.
4. Avoid lock-in, since you can still use any other provider with SlopCode.
