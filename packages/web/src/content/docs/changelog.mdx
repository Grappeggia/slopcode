## Version highlights

### Rust-only Android runtime

- Android release archives now ship the Rust sidecar runtime directly instead of a Bun bundle.
- `slopcode doctor android --json` reports the Rust runtime and verifies the sidecar path.

### Android home prompt

- Termux sidecar now opens on a SlopCode home prompt instead of eagerly creating a session.
- Typing the first prompt creates the session lazily and submits through the same daemon prompt route.

### Android Termux sidecar

- Android now reports runtime mode, sidecar path, version, and install health through `slopcode doctor android`.
- Termux gates now classify true parity, workflow parity, surface-only support, and blocked OpenTUI work separately.
- Core sidecar workflows continue to improve, while rich OpenTUI/editor/plugin/theme parity remains blocked or surface-only until shared native support lands.
