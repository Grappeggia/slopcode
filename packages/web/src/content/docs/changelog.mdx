## v0.2.184

Released July 3, 2026.

- Added Goal mode regression coverage.
- Hardened Windows compaction retry-backoff coverage.

## v0.2.183

Released July 3, 2026.

- Added Goal mode for persistent session goals.
- Remind active sessions of their current goal.
- Moved Docs out of primary agent tab rotation.

## v0.2.182

Released July 2, 2026.

- Added Claude-compatible `/model` and `/mcp` TUI aliases.
- Made `/copy` copy the last assistant response, with transcript copy at `/copy-session` and `/transcript`.
- Added `/usage` with `/cost` and `/stats` aliases for session tokens and cost.

## v0.2.181

Released July 2, 2026.

- Ask quick `/btw` side questions without interrupting the main session.
- Stream side-question answers in a dismissible TUI overlay.
- Keep side-question answers out of chat history and tool execution.

## v0.2.180

Released July 2, 2026.

- Compact TUI spacing for small terminals.
- Reduced prompt, transcript, sidebar, dialog, and diff viewer gutters.
- Preserved home zero-state layout while improving session density.

## v0.2.179

Released July 2, 2026.

- Fixed the TUI exit epilogue SlopCode wordmark.

## v0.2.178

Released July 2, 2026.

- Fixed Ripgrep fallback search startup on Windows.
- Stabilized Windows path, prompt, and compaction tests.
- Updated post-release docs and CI metadata.

## v0.2.177

Released July 2, 2026.

- Added upstream-compatible `--mini`, `--auto`, and `--yolo` run modes.
- Added `slopcode attach --mini` with replay controls.

## v0.2.148

Released June 13, 2026.
