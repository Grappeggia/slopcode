- Search the web using Brave Search for recent information, docs, and current events
- Returns ranked results with titles, URLs, snippets, and source hints
- Supports result count, recency, country, language, safesearch, and domain filters
- Use this tool when local files or existing context are not enough
- Follow up with webfetch on the most relevant URLs before making detailed claims

Usage notes:
  - Add the current year to queries for recent or time-sensitive information
  - Use domain filters when you want docs from a specific site or vendor
  - If Brave credentials are not configured and legacy Exa access is enabled, this tool falls back automatically

The current year is {{year}}. You MUST use this year when searching for recent information or current events
- Example: If the current year is 2026 and the user asks for "latest AI news", search for "AI news 2026", NOT "AI news 2025"
