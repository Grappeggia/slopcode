---
title: "Memory"
description: "Persist useful context across local sessions"
---

Memory lets SlopCode remember durable preferences and project facts across sessions.

It is off by default, so nothing is learned or reused until you opt in.

---

## Enable it

Turn it on in your SlopCode config with `memory.enabled`.

```json title="slopcode.json"
{
  "$schema": "https://slopcode.dev/config.json",
  "memory": {
    "enabled": true
  }
}
```

Set it in global config for all projects, or in project config for one repo.

Project config can enable project memories, but global memories are reused only after you explicitly opt the current session in with `/memory` or `/memories`.

---

## Limit context

Use `memory.limit` to choose how many relevant entries can be injected into a prompt.

```json title="slopcode.json"
{
  "memory": {
    "enabled": true,
    "limit": 8
  }
}
```

The default is `8`; SlopCode caps the effective value at `50`.

---

## Keep private

Entries are stored only in SlopCode's local SQLite database.

SlopCode redacts common secrets before persistence, including tokens, API keys, and passwords.

Do not deliberately store credentials in memory. Redaction is a defense-in-depth safeguard, not a substitute for keeping secrets out of prompts.

---

## Inject briefly

Relevant entries are added as temporary prompt context when a session uses them.

That context is sent to the active model provider as part of the request. When automatic extraction is enabled, each completed turn also makes a separate request using the configured memory agent or selected small model; provider charges may apply and are not included in the parent session's displayed usage. Automatically extracted entries are restricted to the current project. Global entries require explicit creation and session opt-in.

The entries themselves are not written to the transcript, shared with `/share`, included in `/export`, or copied by transcript commands.

---

## Manage entries

Open the TUI and run `/memories` or `/memory`.

From there, add project or global entries, toggle entries, delete them, and opt the current session in or out.
